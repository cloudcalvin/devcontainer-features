# Development Container Features

| Feature                              | Description                                                                                                                  |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| [ace](src/ace/README.md)             | Installs ace, a CLI tool that defines and runs AI agents from a single YAML file. Supports multi-agent setups and MCPServer. |
| [aichat](src/aichat/README.md)       | Installs aichat, a powerful AI chat client for your terminal.                                                                |
| [ast-grep](src/ast-grep/README.md)   | Installs ast-grep.                                                                                                           |
| [cagent](src/cagent/README.md)       | Installs cagent.                                                                                                             |
| [codex-cli](src/codex-cli/README.md) | Installs OpenAI Codex CLI.                                                                                                   |
| [gitleaks](src/gitleaks/README.md)   | Installs gitleaks.                                                                                                           |
| [lefthook](src/lefthook/README.md)   | Installs lefthook.                                                                                                           |
| [persistent-config](src/persistent-config/README.md) | Persists selected home-relative configuration directories.                                                     |
| [task](src/task/README.md)           | Installs Task.                                                                                                               |
